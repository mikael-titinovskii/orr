Local access

Management requests require no authentication header. ORR reads OPENROUTER_API_KEY from its environment or dotenv configuration for upstream operations; clients do not resend it.

The API is accessible to anyone who can reach ORR_LISTEN. Keep the default loopback address for local use.

This page makes no billable requests. Import the schema into an OpenAPI-compatible client to use the API.

Background jobs

Refresh and benchmark submissions return 202 with a polling URL in Location. One management job runs at a time. Matching submissions share the running job; conflicting work returns 409. The last 64 jobs remain available until restart.

Benchmarks make billable upstream requests and run for up to 10 seconds. Refresh requests have a 30-second timeout. Manual pins are preserved, and accepted jobs finish before shutdown saves final statistics.

OpenRouter traffic uses /v1/*. Management uses /api/v1/*. Missing measurements are returned as null.
